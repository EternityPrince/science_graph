Coming up with a scientific naming method may not seem like a big deal, but it really is. Prior to Linnaeus, there was no consistent way to name species. Names given to organisms by scientists were long and cumbersome. Often, different scientists came up with different names for the same species. Common names also differed, generally from one place to another. A single, short scientific name for each species avoided a lot of mistakes and confusion.
