Note Today, new elements are usually named after famous scientists. The names of the elements can be cumbersome to write in full, especially when combined to form the names of compounds. Therefore, each element name is abbreviated as a one- or two-letter chemical symbol. By convention, the first letter of a chemical symbol is a capital letter, while the second letter (if there is one) is a lowercase letter. The first letter of the symbol is usually the first letter of the element’s name, while the second letter is some other letter from the name. Some elements have symbols that derive from earlier, mostly Latin names, so the symbols may not contain any letters from the English name.
